- ### Installation

```


- #### HTTPS
```
git clone https://github.com/Squashedapricot/Lazyvim_config.git
mv $(pwd)/Lazyvim_config $HOME/.config/nvim
cd $HOME/.config/nvim
nvim
```

- #### SSH
```
git clone git@github.com:Squashedapricot/Lazyvim_config.git
mv $(pwd)/Lazyvim_config $HOME/.config/nvim
cd $HOME/.config/nvim
nvim
